### 🤖 GitHub Mirror — Telegram Work Log

Bot pessoal desenvolvido em **Python** que transforma mensagens enviadas pelo Telegram em registros versionados automaticamente em um repositório privado no GitHub.

```text
Mensagem no Telegram
        ↓
     Python Bot
        ↓
      log.md
        ↓
    Git Commit
        ↓
     Git Push
```

O projeto foi criado para manter um **registro privado e genérico de atividades**, automatizando todo o fluxo entre mensagem, atualização do arquivo e versionamento.

Possui controle de acesso por usuário autorizado, configuração segura através de variáveis de ambiente e integração automatizada com Git.

🔒 **Repositório privado**

`Python` `Telegram Bot API` `Git` `GitHub` `Automation`
