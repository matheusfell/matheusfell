# 🚀 Projetos

Alguns projetos pessoais que representam áreas que gosto de explorar:

### 🛰️ Ambush

Sistema para **monitoramento de aplicações e serviços**, centralizando status, disponibilidade e acompanhamento da saúde de sistemas.

`Python` `FastAPI` `Monitoring` `Automation`



### 🌸 Meu Perfume

Aplicação web para descoberta e exploração de perfumes, desenvolvida com foco em experiência de usuário, organização de informações e construção de uma interface moderna e responsiva.

`React` `Vite` `JavaScript` `Tailwind`

### 🎵 Playlist AI

Aplicação que utiliza Inteligência Artificial para gerar playlists no Spotify a partir de prompts em linguagem natural.

O sistema utiliza um modelo local através do Ollama para interpretar o pedido do usuário, sugerir músicas, localizar as faixas através da Spotify Web API e criar automaticamente a playlist na conta autenticada.

`Node.js` `Express` `Spotify API` `OAuth Ollama Artificial Intelligence`

### 🤖 GitHub Mirror — Private Work Log

Bot pessoal desenvolvido em Python que transforma mensagens enviadas pelo Telegram em registros versionados automaticamente em um repositório privado do GitHub.

Telegram
   ↓
Python Bot
   ↓
log.md
   ↓
Git Commit
   ↓
Git Push

O projeto foi criado para manter um registro privado e genérico de atividades, automatizando todo o fluxo entre mensagem, atualização do arquivo e versionamento no GitHub.

Possui controle de acesso por usuário autorizado, configuração segura através de variáveis de ambiente e execução automática de comandos Git.

🔒 Repositório privado

`Python` `Telegram Bot` `Git` `GitHub Automation` 

### 🛋️ MobiliaAI

Projeto conceitual de uma aplicação mobile para visualizar como móveis ficariam dentro de ambientes reais utilizando câmera, Realidade Aumentada, Visão Computacional e Inteligência Artificial.

A proposta é permitir que o usuário informe dimensões e imagens de um móvel e consiga posicioná-lo virtualmente dentro do ambiente antes da compra.

`Mobile` `Computer Vision` `Augmented Reality` `AI` `Backend`
